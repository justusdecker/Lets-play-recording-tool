Workflow (Production)

Record

Select the desired lets play

Press "connect"

Start recording in OBS.

IMPORTANT

Common Issues

Is OBS open? - If not open OBS!

Did you opened the OBS webserver correctly? - If not read this

Did you set the OBS Settings in LPRT: IP, Port & Password? - If not read this

Thumbnail Generation

Select the desired lets play & episode range.

press run

NOTE

Make sure you have created the Thumbnail Automation Data

Having any trouble? You find here the Troubleshooting Page

Audio Fetch

Select the desired lets play & episode range.

press run

NOTE

Make sure the video you want to extract from existing videos!

Audio Fix

Audio Fix does:

  1. Lowpass
  2. Highpass
  3. Loudness Normalization & Limiting

Select the desired lets play & episode range.

press run

NOTE

Make sure the audio you want to fix exists!

Send to Audacity

Select the desired lets play & episode range.

press run

  1. Import
  2. Get Noise Profile
  3. Select Track
  4. Noise Reduction
  5. Do this until all Audios are done
  6. Export all tracks in batch
  7. Answer the lprt filedialog

IMPORTANT

Common Issues

Is Audacity open? - If not open Audacity!

Is the mod-pipe enabled? - If not read this

Exported files needs to have only an underscore as prefix! Nothing else!

IMPORTANT

Make sure the audio you want to send exists!

Compare & Render

Select the desired lets play & episode range.

press run

Change the background audio volume so that you can hear both your mic & desktop sound perfectly fine. Now you have 3 cases:

  1. All Audiolevels are the same
    • In this case click on the up button until you at the end of the episodes!
  2. Audiolevels are different(like you changed ingame sound volume)
    • In this case you must edit the desktop audio manually(e.g. in Audacity)

Set Title

Select the desired lets play & episode range.

press run

Set title or take screenshots while preview your video

Deploy

Select the desired lets play & episode range.

press run

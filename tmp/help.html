Setup

Installing LPRT

Pretty simple just unpack the .zip or .7z file into a folder of your choice.

First Startup

Open lprt.exe

Connecting LPRT to OBS

  1. Installation
    • Download & Install OBS like you do it with any other program. Get it from the OBS Website or use the Steam version

    • IMPORTANT

      OBS Version 30 or greater recommended.

  2. Set your OBS Settings
    • Go to Settings
    • Go to Output & set the Output Mode to Advanced
    • The Encoder Settings
    • The Recording Settings
    • The Audio Settings
  1. Enable the OBS Webserver
    • Open OBS
    • Click on the tools dropdown
    • Click on Websocket Server-Settings
    • Activate Websocket Server
    • Activate authentification!
    • Generate a new password
    • Click on show Connection information
    • Update the OBS Settings in LPRT
    • You can change the settings manually by copy the ip, port & password into {ROOT}/obs_settings.json.
         {
       "ip": "{your ip}",
       "port": "{your port}",
       "pw": "{your password}",
       "timeout": 1
   }
  2. First Recording
    • Open LPRT & OBS
    • Go to the recording page
    • Select a lets play(Nothings shows up? No problem.)
    • Press the connect button
    • Start Recording in OBS
    • You see your recording time & LPRT will create data for further automation.

Connecting to Audacity

  1. Installation - Audacity itself
    • Download & Install Audacity like you do it with any other program. (You need to remember the audacity filepath!)
    • Get the 3.0.0 Audacity version from here

    • IMPORTANT

      Currently only Audacity 3.0.0 is supported.

      Other versions might not work as expected!

  2. First startup
    • On the first startup you need to enable the modpipe.
    • Go to Edit > Settings
    • Go to Module & enable mod-script-pipe
    • Restart Audacity for the next step
  3. Installation - FFMPEG for Audacity
    • Download the 2.2.2 version from here

    • IMPORTANT

      Currently only FFMPEG-Audacity 2.2.2 is supported.

    • Go to Edit > Settings
    • Goto Libraries > search
    • A filedialog open up.
    • Select the avformat-55.dll normally located in C:\Program Files\FFmpeg For Audacity\. (Only if Audacity does this not automatically)
    • Restart Audacity

Troubleshooting

Troubleshooting

IPV6 & IPV4 confusion

Sometimes OBS shows you the IPV6 instead of the IPV4. You need to open cmd & type in ipconfig Look for the IPV4 Address, copy this into LPRT - OBS Settings.

IP changed

Sometimes your ip changes & LPRT will not recognize these changes. You need to manually adjust the ip adress in {ROOT}obs_settings.json

Password wrong

Simply adjust your password in {ROOT}obs_settings.json

If you're issue is not listed here, then please create an issue for this.

Audacity connection is sometimes pure bs

Known Issues

LPRT connecting while OBS is recording

This is a rare issue but can still ruin your day, if you are not careful!

Make sure that OBS is not recording while connecting!
